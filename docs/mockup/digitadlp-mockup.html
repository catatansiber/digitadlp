DigitaDLP

Aplikasi untuk menemukan dan menyensor data pribadi di dokumen instansi sebelum dirilis. Satu dokumen sumber menghasilkan tiga versi: Publik, Internal, dan Rahasia. Semua diproses di server instansi.

Alur kerja

Dari upload sampai rilis

Staf upload PDF/DOCX→ Sistem deteksi data pribadi→ Sistem sarankan label→ Pemeriksa cek dan koreksi→ Tiga versi dibuat→ Rilis + catatan audit

Rencana desain

Keputusan yang sudah diambil

Deteksi

  • Pola (regex): NIK, KK, NPWP, HP, email, rekening
  • NER IndoBERT: nama, alamat
  • OCR Tesseract untuk PDF scan

Sensor

  • Teks benar-benar dihapus, tidak hanya ditutup
  • PDF scan: piksel ditimpa, lalu OCR ulang
  • Metadata dan riwayat revisi dibuang

Akses

  • Rahasia: unit pemilik + Pemeriksa
  • Pemeriksa tidak boleh menyetujui unggahan sendiri
  • Login akun lokal

Teknologi

  • Python + FastAPI (backend)
  • React (tampilan)
  • PostgreSQL, antrean kerja, file terenkripsi
  • On-premise, tanpa GPU
